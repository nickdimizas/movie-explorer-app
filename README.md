# React + TypeScript Movie Explorer

A modern, responsive web application for searching movies and series, built with React, TypeScript, TanStack Query, and Tailwind CSS (v4) using the OMDb API.

## Tech Stack

- **Framework:** React + Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Data Fetching & Caching:** TanStack Query (React Query) + Axios
- **API:** OMDb API

## Key Features

- Live search with custom Debounce hook
- Filter by type (Movies / Series)
- Pagination control
- Loading and Error state handling
- Fully responsive UI
